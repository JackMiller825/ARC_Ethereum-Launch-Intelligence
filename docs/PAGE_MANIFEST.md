# Page-by-page design + asset manifest

1. OVERVIEW `/`: editorial command-center hero, mint orbital artwork, four major metrics, dark chart, strategy panel, watchlist, transaction table. Assets: `public/assets/hero-orbit.svg`, `arc-mark.svg`; screenshot `previews/01-overview.png`.
2. ANALYSIS `/analysis`: large green-lit CA search, verified contract identity, data-boundary disclaimer, time interval control, KPIs, swap chart, analytics coverage and trade table. Screenshot `previews/02-analysis.png`.
3. PLANNER `/planner`: editable capital assumptions, seven launch phases with persistent-on-page checklist, dynamic scenario calculator and JSON export. Screenshot `previews/03-planner.png`.
4. BOTS `/bots`: six strategy classes, selection cards, deep-dive feature/evidence panel. Screenshot `previews/04-bots.png`.
5. WALLETS `/wallets`: wallet filter and synthetic attribution table. Screenshot `previews/05-wallets.png`.
6. HISTORY `/history`: token library cards for SISH reference and two explicit fake examples. Screenshot `previews/06-history.png`.
7. SETTINGS `/settings`: source readiness, audit methodology and production-gate descriptions. Screenshot `previews/07-settings.png`.

Color system: #0b101b backdrop; #121c2e cards; #66e7a8 signal mint; #80aaff analytic blue; #f4ad82 caution; Space Grotesk headings + DM Sans body + DM Mono telemetry. Desktop sidebar 254px, fixed height; responsive mobile overlay. All visual geometry built from real HTML/CSS/SVG; no flattened mockup substitution.
