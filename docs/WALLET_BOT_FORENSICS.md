# Wallet and bot forensics

Classifications stay on `arc-heuristic-v2`. Each stored trade keeps its evidence lines, confidence band, and the rule that raised the class. A first-block buy is speed evidence. An externally owned account calling a public router is assisted execution, not proof of an autonomous operator. Unknown and low confidence stay outside the automated buy total.

Wallet Explorer shows the signer timeline, method, priority fee when the trade stored it, and other saved launches that contain the same address. The overlap table lists signers that appear in more than one saved index, with aggregate valued buys and sells. The note on that table says a repeated address is not one person and that exchange funding is not shared control.

Balance and Blockscout reads are optional. If they fail, no funding source is inferred.
